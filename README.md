# Russisch Soundboard – GitHub Pages

Dateien dieses Ordners direkt in das Hauptverzeichnis eines GitHub-Repositories hochladen.

GitHub:
1. Neues Repository anlegen.
2. index.html, manifest.json, sw.js und den Ordner icons hochladen.
3. Settings → Pages öffnen.
4. Unter Build and deployment: Source = Deploy from a branch.
5. Branch = main, Ordner = /(root), Save.
6. Die von GitHub angezeigte HTTPS-Adresse in Safari auf dem iPhone öffnen.
7. Teilen → Zum Home-Bildschirm → Hinzufügen.

Die Web-App verwendet die russische Systemstimme des Geräts über die Web Speech API.
